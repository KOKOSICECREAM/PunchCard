Verify a PunchCard token.

Anyone can copy a name, a logo or a description. Only PunchCard’s program on Solana can create a token’s PunchCard record, so that’s what we check.

How it works

Every token launched on the PunchCard Launchpad gets a permanent record on Solana, created by PunchCard’s program 6Soj…TzUp. Nobody else can create one. If a token has that record, it’s an official PunchCard launch; if not, it isn’t, whatever its name or description says.

Official PunchCard pages and links only come from punchcard.club and @punchcard_club.
